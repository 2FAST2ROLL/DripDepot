# 👟 DripDepot

**DripDepot** is a modern streetwear shopping website built for showcasing and selling curated fashion pieces.

The site features a clean, dark streetwear-inspired design with product browsing, brand filtering, search, product details, and a shopping cart.

## 🔥 Features

- 🛍️ Browse a large streetwear catalog
- 🔎 Search for products
- 🏷️ Filter products by brand
- 👕 Filter products by category
- 🛒 Add products to a shopping cart
- 📏 Select clothing sizes
- 💰 Automatic cart total calculation
- 📱 Responsive design for phones, tablets, and computers
- 🌑 Modern dark-themed streetwear UI
- ⚡ Built with vanilla HTML, CSS, and JavaScript
